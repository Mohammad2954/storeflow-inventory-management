# StoreFlow 📦

**A Store & Inventory Management Dashboard**

StoreFlow is a store and inventory management dashboard built with React and Tailwind CSS. The project aims to provide a simple and organized interface for managing products, monitoring inventory, and tracking store operations.

This project is currently in its **first development version (v0.1.0)**. The current focus is on building the user interface, organizing reusable components, and preparing the structure for future features.

## ✨ Features

- 📊 Dashboard layout for store management
- 📦 Product management interface
- 🗃️ Inventory management interface
- 🔎 Product information, categories, and search-ready data structure
- ⚠️ Inventory status indicators, including low-stock and out-of-stock products
- 🎨 Modern UI with a navy and green color palette
- 🌐 Persian, right-to-left (RTL) interface
- 🧩 Reusable React components
- 🧪 Sample data for development and UI testing

## 🛠️ Tech Stack

- **React** — Building the user interface
- **Vite** — Development server and build tool
- **Tailwind CSS** — Styling and responsive layouts
- **JavaScript** — Application logic
- **React Icons** — Interface icons

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd StoreFlow
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
